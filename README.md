# Computational Thinking 4 – Kollaboratives Whiteboard

In diesem Kurs bauen wir Schritt für Schritt eine kollaborative Whiteboard-Plattform, ähnlich wie Miro. Auf einem gemeinsamen Board kann man Post-its anlegen, bearbeiten und anordnen und in Echtzeit mit anderen zusammenarbeiten.

Jeder Termin führt ein klar benanntes Architekturmuster ein. So bleibt der Code nachvollziehbar, auch wenn das Projekt wächst.

## Los geht's

1. Forke dieses Repo.
2. Arbeite in deinem Fork weiter – mit einem KI-Coding-Assistenten wie Claude Code.

## Was hier drin ist

- **`CONTEXT.md`** beschreibt, was gebaut wird und mit welchem technischen Setup.
- **`CLAUDE.md`** enthält die Arbeitsregeln für die KI, zum Beispiel: einfach halten, nur gezielte Änderungen, keine Datei mit mehr als 200 Zeilen.
